USB screen mirror · 0.1.19-alpha

A window into FIELD.

Bring the FM-1’s display onto your computer. Move this window to a monitor, go fullscreen, or capture it in OBS.

Connect a USB data cable and leave FIELD running normally.

Requires FIELD 0.1.8 or later and desktop Chrome or Edge with MIDI permission. This is a read-only display; use the FM-1’s controls to play.

The computer supplies video to the monitor. The FM-1’s USB-C port does not output HDMI or DisplayPort. Mirroring releases its memory when disconnected and closes before installing firmware from this site.
