Network throughput & playback reserve · 0.1.4-alpha
The TCP receive window is doubled to improve throughput on delayed connections. Playback starts and refills with nearly the full existing audio reserve; startup may take longer. Includes a three-bar battery indicator (USB when host-powered), country/state browsing and the static globe. This update passes software tests and still needs device testing. First WiFi startup downloads the location index and may take three minutes or longer. Back up your existing firmware’s projects using its own backup tools first.

Connect the FM-1 by USB, then press Install. It works in Chrome or Edge; the browser asks once to allow MIDI: allow it.

Do not unplug the USB cable while writing.
